# Repository file summaries

Generated by walking every directory and appending a one-line summary per file.

## / (repository root)

- `.gitignore`: Ignores node_modules, dist, *.local files, and .DS_Store.
- `index.html`: Vite HTML shell titled Kingdom of Lexica that loads Cinzel/Crimson Pro fonts and mounts `/src/main.tsx`.
- `package.json`: Private npm package `onboarding-crosses` 0.1.0 with React 19, Vite 6, and TypeScript 5.8 scripts.
- `package-lock.json`: npm lockfileVersion 3 pinning React, Vite, TypeScript, and their transitive dependencies.
- `README2`: Short placeholder file containing only the text "this is a test".
- `README.md`: Project readme for the Kingdom of Lexica campaign tic-tac-toe onboarding game, including run/build steps and lord table.
- `tsconfig.app.json`: TypeScript config for the `src` app with strict ES2022/DOM/react-jsx settings.
- `tsconfig.json`: Solution-style tsconfig that references the app and node configs.
- `tsconfig.node.json`: TypeScript config for `vite.config.ts` targeting ES2023 with strict checks.
- `vite.config.ts`: Vite config enabling the official React plugin.

## /src

- `App.tsx`: Root React app that routes title/map/briefing/battle screens and persists campaign progress plus Lord O draw tracking.
- `main.tsx`: React 19 entry that mounts `App` into `#root` under StrictMode.
- `vite-env.d.ts`: Triple-slash reference so TypeScript picks up Vite client types.

## /src/campaign

- `letters.ts`: Campaign letter registry defining lords O/A/B/E/L/M/U/K with decrees, rules, AI strategy, and game factories.
- `progress.ts`: localStorage campaign progress helpers for unlocks, victories, reset, and Lord O boredom after draws.

## /src/components

- `BattleBriefing.tsx`: Pre-battle screen showing a lord's title, decree, rules, and optional Lord O boredom quote.
- `BattleView.tsx`: Active battle UI that picks Classic/Connect/Ultimate grids, reports outcomes, and shows retreat/rematch/rules.
- `ClassicGrid.tsx`: Button grid for classic and overflow boards, including blocked bastions and oldest-mark highlighting.
- `ConnectGrid.tsx`: Connect-style column drop UI with gravity cells for Lord A's avalanche arena.
- `OutcomeOverlay.tsx`: Modal overlay for win/loss/draw copy, including Lord O boredom and draw-count flavor.
- `ThroneMap.tsx`: Campaign map of unlocked/defeated/locked letter thrones plus a locked-letter teaser row.
- `TitleScreen.tsx`: Title screen for Kingdom of Lexica with continue or new-game actions.
- `UltimateGrid.tsx`: Nine-board ultimate tic-tac-toe grid that highlights the active legal realm.

## /src/game

- `classic.ts`: Classic N×N tic-tac-toe engine with blocked cells, misère, crown scoring, bonus placements, and win/draw evaluation.
- `connect.ts`: 7×6 connect-four engine with gravity drops, column validation, and four-in-a-row checks.
- `engine.ts`: Unified game dispatcher for clone/legal-moves/validate/apply across classic, connect, overflow, and ultimate.
- `overflow.ts`: 5×5 FIFO overflow mode that removes a side's oldest mark once more than three are placed.
- `types.ts`: Shared TypeScript types for sides, actions, validation, and all game-state variants.
- `ultimate.ts`: Ultimate tic-tac-toe rules: nine 3×3 boards, active-board routing, and meta-board winners.

## /src/game/ai

- `lordO.ts`: Lord O boredom constant, flavor thinking lines, and a throwing-move picker that gifts wins after two draws.
- `minimax.ts`: Alpha-beta minimax, heuristics, legal-action conversion, and `chooseAiMove` for lord-side play.
- `strategies.ts`: AI strategy router for perfect, weak, misère-fool, connect, and bored Lord O moves.

## /src/hooks

- `useBattle.ts`: Battle hook that reduces game actions, delays lord AI moves, and exposes play/reset plus thinking copy.

## /src/styles

- `app.css`: Component styles for title, throne map, briefing, battle grids, connect columns, overlay, and epilogue.
- `tokens.css`: Global CSS variables, reset, dark royal theme, fonts, and reduced-motion rules.
