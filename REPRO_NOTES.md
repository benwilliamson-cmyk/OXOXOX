- `index.html`: Vite HTML shell titled Kingdom of Lexica that mounts `#root` and loads `/src/main.tsx` plus Cinzel/Crimson Pro fonts.
- `package.json`: Private `onboarding-crosses` 0.1.0 package with Vite/React 19 scripts and TypeScript tooling.
- `package-lock.json`: npm lockfile v3 pinning React 19, Vite 6, TypeScript 5.8, and related transitive deps.
- `README2`: Placeholder file containing the text `this is a test`.
- `README.md`: Kingdom of Lexica campaign tic-tac-toe onboarding docs covering run/build steps, lords, and how to add a letter.
- `tsconfig.app.json`: Strict ES2022/DOM TypeScript config for the `src` app with React JSX and bundler resolution.
- `tsconfig.json`: Solution-style tsconfig that references `tsconfig.app.json` and `tsconfig.node.json`.

## /src

- `src/App.tsx`: Top-level campaign UI that routes title/map/briefing/battle screens and persists victories and Lord O draws.
- `src/main.tsx`: React 19 entry that mounts `App` under StrictMode on `#root`.
- `src/vite-env.d.ts`: Triple-slash reference that pulls in Vite client type definitions.

## /src/campaign

- `src/campaign/letters.ts`: Defines letter-lord IDs, campaign order, and per-lord titles, rules, AI strategy, and game-state factories.
- `src/campaign/progress.ts`: Loads and saves campaign progress in `localStorage`, including unlocks, victories, and Lord O draw counts.

## /src/components

- `src/components/BattleBriefing.tsx`: Pre-battle screen showing a lord's glyph, decree, rules, and begin/back actions.
- `src/components/BattleView.tsx`: In-battle layout that picks the right grid, reports outcomes, and shows Lord O boredom/hint banners.
- `src/components/ClassicGrid.tsx`: Clickable NxN grid for classic and overflow modes, including blocked bastions and oldest-mark highlights.
- `src/components/ConnectGrid.tsx`: Connect-style column-drop board with per-column drop buttons and gravity-stacked cells.
- `src/components/OutcomeOverlay.tsx`: Modal copy and actions for win, loss, and draw, with special Lord O dialogue.
- `src/components/ThroneMap.tsx`: Campaign map of unlocked, current, defeated, and locked letter thrones plus an epilogue.
- `src/components/TitleScreen.tsx`: Title screen with continue/new-game buttons based on saved progress.
- `src/components/UltimateGrid.tsx`: Nine-board ultimate tic-tac-toe UI highlighting legal cells and active sub-boards.

## /src/game

- `src/game/classic.ts`: Classic-grid engine: create/legal/validate/apply/evaluate with blocked cells, misère, crown cells, and bonus placements.
- `src/game/connect.ts`: 7×6 connect-four engine with gravity drops, four-in-a-row checks, and column validation.
- `src/game/engine.ts`: Shared dispatcher that clones, lists legal moves, validates, and applies actions across all game kinds.
- `src/game/overflow.ts`: 5×5 FIFO overflow mode that keeps at most three marks per side and reuses classic win evaluation.
- `src/game/types.ts`: Shared TypeScript types for sides, actions, and classic/connect/overflow/ultimate game states.
- `src/game/ultimate.ts`: Ultimate tic-tac-toe engine with nine boards, active-board routing, and meta-board winners.

## /src/game/ai

- `src/game/ai/lordO.ts`: Lord O boredom threshold, flavor thinking lines, and a throwing-move picker that gifts wins after two draws.
- `src/game/ai/minimax.ts`: Alpha-beta minimax, heuristics, legal-action conversion, and best-move selection for lord turns.
- `src/game/ai/strategies.ts`: Strategy router for perfect, weak, misère-fool, connect, and bored-Lord-O move choice.

## /src/hooks

- `src/hooks/useBattle.ts`: Battle hook that reduces game actions, delays lord AI moves, and exposes play/reset plus thinking state.

## /src/styles

- `src/styles/app.css`: Layout and component styles for title, throne map, briefing, battle grids, overlays, and buttons.
- `src/styles/tokens.css`: Design tokens and global resets for the dark gold-and-purple Lexica theme.
